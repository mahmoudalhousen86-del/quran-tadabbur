# نظام الحضور والانصراف وحساب الرواتب

تطبيق ويب عربي (RTL) لإدارة حضور الموظفين وحساب الرواتب بشكل كامل.

## المميزات

- **لوحة تحكم**: حضور اليوم، الغياب، ملخص الرواتب
- **الموظفون**: إضافة/تعديل/حذف مع الراتب والبدلات وجدول الدوام
- **حضور وانصراف**: تسجيل فوري أو يدوي مع احتساب التأخير والإضافي
- **الإجازات**: اعتيادي / مرضي / طارئ / بدون راتب مع الموافقة
- **الرواتب**: مسير شهري + قسيمة تفصيلية
  - أساسي + بدلات
  - أجر ساعات إضافية
  - مكافآت وسلف وخصومات
  - خصم تأخير / غياب / إجازة بدون راتب
- **التقارير**: رسوم بيانية للحضور وتوزيع الرواتب
- **الإعدادات**: سياسات الدوام والخصومات
- البيانات تُحفظ في المتصفح (`localStorage`)

## التشغيل

```bash
cd attendance-app
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر (عادة `http://localhost:5173`).

## البناء

```bash
cd attendance-app
npm run build
npm run preview
```

## معادلة الراتب (مختصر)

```
الإجمالي = الأساسي + السكن + المواصلات + بدلات أخرى + الإضافي + المكافآت
الصافي   = الإجمالي − (تأخير + غياب + إجازة بدون راتب + سلف + خصومات)
```
